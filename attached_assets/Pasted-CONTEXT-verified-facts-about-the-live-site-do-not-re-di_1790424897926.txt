TASK 2 — Stop the catch-all serving index.html with HTTP 200

This is the root cause and the most important fix.

In app.yaml, the handlers list is evaluated top to bottom. There is almost
certainly a trailing catch-all like:

  - url: /.*
    static_files: dist/index.html
    upload: dist/index.html

Change the behaviour so that an unknown path returns HTTP 404 with a proper
404 page, NOT HTTP 200 with the homepage.

Requirements:
- / must still serve the homepage.
- Every path that has a real page file must still serve that page.
- Any path with no matching file must return HTTP 404.
- Add a simple 404 page with the site header, a short "page not found"
  message, and a link back to /.

If the site genuinely needs SPA-style client routing for some section,
scope the catch-all to that subtree only (e.g. /app/*), never to /.*.
